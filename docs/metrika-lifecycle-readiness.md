## D. Исправление повторных просмотров

Причина: stopAnalytics сбрасывал lastPath при любом прекращении работы, включая временную паузу. Возобновление снова отправляло текущий адрес.

Теперь идентификатор учтённого просмотра содержит счётчик, номер посещения маршрута и внутренний ключ действительного согласия. Пауза останавливает SDK и блокирует поздние операции, но сохраняет учтённое посещение. Изменение маршрута наблюдается даже при паузе. Поэтому A → B → A считается новым посещением A, в том числе если переходы происходили при открытых настройках. Промежуточные страницы во время запрещённой аналитики не отправляются задним числом.

Повторное обновление того же pathname без ухода на другой маршрут не считается новым просмотром. Новый документ после перезагрузки считается новым посещением. Якоря главной не являются отдельными просмотрами. Отзыв очищает учёт; новое действительное согласие создаёт свежий просмотр даже того же URL. Сохранение нового серверного подтверждения также различается от временной проверки прежнего.

Регрессия сначала воспроизведена: тест закрытия настроек получил 4 просмотра вместо 3. После исправления он прошёл. Сохранены проверки одновременных обновлений, отказа, отзыва, нового согласия и поздней загрузки SDK.

## E. Безопасность передаваемых данных

Разрешённый охват прежний: главная, каталог, категории и подкатегории при действительном подтверждённом согласии и допустимом referrer. Запрещены поиск, товары, список покупок, admin, юридические страницы, произвольные fragment и любые непустые query string, включая q, utm_* и yclid.

Отправляются только существующие hit с origin+pathname, постоянным заголовком «Автозапчасти в Талдоме» и пустым referer. Собственных reachGoal, новых параметров, идентификаторов посетителя, текста поиска, результатов поиска и контактных значений не добавлено. ReceiptId используется только в памяти приложения для дедупликации и не попадает в аргументы SDK — это проверено тестом.

Сохранены проверка адреса до загрузки SDK, referrerPolicy=no-referrer для tag.js и выход из документа с SDK перед поиском/другими запрещёнными маршрутами. Удаление script или cookie не выдаётся за доказательство остановки JavaScript: сохранены destruct, disableYaCounter, fencing поколения и очистка собственных очередей. Проверка фактического сетевого поведения SDK остаётся отдельным этапом.
