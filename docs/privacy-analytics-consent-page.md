# Отдельная страница согласия на Яндекс.Метрику

Проверено 17 октября 2026 года на локальной production-сборке, `http://127.0.0.1:3115`.

## Результат

Полный документ доступен по `/privacy/analytics-consent`, включая прямой переход и обновление страницы. Существующая ссылка «Прочитать полное согласие» в настройках открывает его в новой вкладке (`target="_blank"`, `rel="noopener noreferrer"`). В исходной вкладке сохраняются открытые настройки, положение их прокрутки, состояние переключателя и сохранённый выбор. Чтение документа не отправляет POST согласия и не загружает собственный SDK Метрики.

Страница использует существующие Header, Footer и CSS страницы `/privacy`. Прокрутка обычная, браузерная; документ не помещается в dialog. Один h1 и десять разделов с h2, буквальная нумерация списков. На ширине до 350 px только заголовок нового документа имеет размер 28 px, чтобы длинные слова оригинала помещались без однобуквенных переносов. Основной текст остаётся 16 px. Старая ветка модального документа, её обработчики и исключительные стили удалены.

## Сохранность текста и утверждённых элементов

Единый источник `src/features/privacy/consent-content.ts` не изменён. Проверка байтов исходной строки с утверждённым приложением `855899a2-7e85-4db0-b63c-c11594d8d0b8/Вставленный текст.txt` прошла. SHA-256: `f801a44356ed08df59a848e25c006cd540e74efcf4a4dd08c50dd29057095d82`; версия документа прежняя. В DOM на всех восьми размерах проверено совпадение полного текста с нормализацией только пробельных символов, один h1 и все десять h2.

Пиксельное сравнение с сохранёнными утверждёнными снимками из `artifacts/privacy-visual-review/` показало полное совпадение области desktop-баннера, области desktop-настроек и всего desktop-снимка `/privacy`. Результат: `artifacts/privacy-analytics-consent-page/visual-preservation.json`. CSS работающих баннера и настроек не менялся; удалены только правила неиспользуемого читателя. Уведомление Liquid Glass и его CSS не изменены. Сравнение хешей исходных файлов с состоянием перед задачей записано в `scope-verification.json` в той же папке.
