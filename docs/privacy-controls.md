# Доработка cookie-баннера и настроек — локальный результат

Дата: 2026-10-14. Ветка `codex/privacy-consent`. Статус: PENDING VISUAL AND FUNCTIONAL APPROVAL. Commit, push, PR, merge и deploy не выполнялись.

1. **Что изменено.** Первоначальный баннер стал немодальным на всех экранах; тексты и состав действий соответствуют последнему утверждённому заданию. Окно настроек получило исправленную рамку аналитики, понятные статусы, единственное сохранение и отдельное уведомление об успехе.
2. **Файлы.** Из существующих runtime-файлов этой задачей изменены только `src/components/site/privacy-settings.tsx`, `src/components/site/privacy-settings.module.css`, `src/features/privacy/privacy-provider.tsx`. Добавлены `src/components/site/privacy-saved-notice.tsx`, его CSS module и `src/features/privacy/analytics-presentation.ts`. Добавлены три теста `scripts/test-privacy-controls{,-browser,-keyboard}.ts`; актуализированы PRODUCT.md, docs/privacy-consent-design.md и описания текущего UI в docs/privacy-consent.md; добавлен этот отчёт. Разница трёх runtime-файлов относительно начала задачи находится в `artifacts/privacy-controls/task.diff`. Уже существовавшие незакоммиченные изменения других задач сохранены.
3. **Созданные компоненты.** PrivacySavedNotice — компактная CSS-интерпретация Liquid Glass для веба, без новой зависимости. analyticsPresentation — небольшая чистая функция для четырёх сочетаний сохранённого выбора и draft и блокировки недоступной конфигурации.
4. **Первоначальный баннер.** Три настоящие кнопки: «Принять», «Только необходимые», «Настроить». Нет крестика, backdrop, блокировки прокрутки или ссылки чтения согласия. Политика доступна по inline-ссылке через существующий механизм возврата. Прокрутка, внешние клики, Escape и посещение Политики не скрывают баннер. Устаревший `autozap.privacy-banner-dismissed.v1` удаляется из sessionStorage; другие ключи не затрагиваются. Отказ останавливает аналитику, сохраняет локальный pending-отказ и скрывает баннер до сети; ошибка сервера не открывает настройки и не показывает toast.
5. **Окно настроек.** Три категории сохранены. «Всегда включены» находится рядом с необходимым заголовком. Переключатель и увеличенная подпись центрированы; сохранённый выбор отделён от draft. Бейдж имеет четыре утверждённых текста; при недоступной конфигурации всегда показывает выключенное состояние, переключатель disabled. Согласие открывается из нижней левой части карточки; исходный полный десятисекционный текст, версия и возврат с фокусом сохранены. Одна кнопка «Сохранить настройки», 240 px на desktop, ширина панели на mobile.
6. **Ошибки.** Явное сохранение при настоящем HTTP 503 оставляет окно открытым и показывает «Не удалось сохранить настройки. Попробуйте ещё раз.» над кнопкой. Успешный ACK, повторная попытка или новое открытие очищают ошибку. Отказ остаётся локально активным даже при сбое сервера. Existing pending outbox и ограничения повторов сохранены; автоматические повторы не создают toast.
7. **Liquid Glass.** Только подтверждённое явное сохранение из настроек закрывает окно и монтирует капсулу «Настройки сохранены» с SVG-галочкой. Вход/выход по 180 ms, видимость около 2.5 s, удаление через 2.68 s. Таймер очищается, повторный успех получает новый ключ. Не перехватывает клики/фокус/скролл; polite live region. Есть reduced-motion, reduced-transparency и fallback без backdrop-filter. После banner actions, ошибок, reload и автоматической доставки уведомление не появляется.
8. **Мобильная версия.** Три одинаковые вертикальные кнопки баннера; поддержаны ширины 320, 375, 390, 430, 768, 1024, 1440. При коротком viewport панель прокручивается; native settings dialog имеет прокручиваемое содержимое и доступную кнопку сохранения. Дополнительный снимок 390×1200 показывает всё содержимое панели; обычный 390×844 показывает реальный внутренний скролл.

Контрольные хеши 21 замороженного файла не изменились. Detector изменённых UI-файлов: []. Независимый finish reviewer: `ship` в пределах текущего интерфейса. JS page errors: 0; загрузок собственного SDK Метрики: 0; в console только два ожидаемых resource errors HTTP503.

ID существующего счётчика и подтверждённые настройки не предоставлены, поэтому настоящее положительное согласие и включение Метрики не проверялись и заблокированы. Отрицательный success ACK и доставка outbox проверены с явно подменённым ответом API; статусы on/pending дополнительно проверены чистой функцией и визуальными моделями. Настоящие iPhone/Safari/Android не проверены.
