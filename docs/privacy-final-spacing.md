## 2. Кнопка «Принять»: только диагностика

Причина затемнения подтверждена в реальном браузере: `disabled: true`, `opacity: 0.65`. Синий градиент уже присутствует даже при disabled. Прозрачность задаётся только правилом `.bannerActions button:disabled` в `src/components/site/privacy-settings.module.css` (рядом с общим правилом для Save).

`src/components/site/privacy-settings.tsx:114`: `disabled={busy || !available}`; `available = configuration.analyticsReady`. Кнопка выключена при сохранении либо при неготовой конфигурации. В этой проверке сохранение не выполнялось, а конфигурация аналитики не готова.

`src/config/privacy.ts:11–19`: `analyticsReady` требует одновременно:

- существующий утверждённый документ `approvedAnalyticsConsent` (он уже задан);
- `YANDEX_METRIKA_COUNTER_ID` как положительное целое число без начального нуля, укладывающееся в safe integer;
- `YANDEX_METRIKA_CONFIGURATION_VERIFIED` со строковым значением `true`.

Последний флаг — фиксация подтверждения настроек владельцем, а не автоматическая проверка кабинета Яндекса. Нельзя выставлять его вместо фактической проверки настроек счётчика. В рамках этой задачи никакие значения не подменялись.

Конфигурация передаётся provider из серверного `src/app/layout.tsx:104`. После применения корректной конфигурации к приложению и новой загрузки страницы `available` станет true, а вне сохранения `busy` будет false: кнопка автоматически станет доступной. Уже открытая вкладка не отслеживает изменения переменных окружения сама. Применение environment может требовать обычного перезапуска/пересборки приложения; это не выполнялось и не авторизовано данной задачей.

Постоянного дополнительного затемняющего правила для enabled-кнопки не обнаружено. Обычный синий градиент задан в `src/app/globals.css:1053`, hover — рядом. После снятия disabled перестанет применяться opacity 0.65. Дополнительная UI-доработка не требуется по текущему коду. Это вывод анализа; активную конфигурацию в браузер не подставляли.

Доступность кнопки не подтверждает состояние PostgreSQL. При нажатии остаются прежние проверки сохранения, signed receipt, готовности конфигурации и серверного ACK; до успешной регистрации собственный SDK не загружается. Кнопка, конфигурация, глобальные стили, provider и API в этой задаче не изменялись.
